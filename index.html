大九九 · 使用说明

让熟练来自间隔练习，而不是死记硬背

这个软件把大九九拆成可解锁的章节、可追踪的进度、可循环巩固的错题。目标不是一次背完，而是在每次练习中稳定提高反应速度和正确率。

1. 操作方法 2. 进度规则 3. 错题巩固 4. 学习理念 5. 反馈与赞赏

1. 操作方法

回车

提交答案。答完之后，回车或点击按钮进入下一题。

章节

左侧点击切换已解锁章节。未解锁章节需要先完成前一章。

数字

打开或收回数字九宫格，适合触屏和低龄学习者。

难度

初学、熟练、速算对应不同限时。速度越快，达成等级越高。

2. 进度规则

未做0% 初学20% 熟练80% 速算100%

每道题只记录历史最高达成难度。章节进度等于该章节所有题目进度的平均值。

答题过程中，本轮新增题目会进入分母，答对进入分子，所以能力值可能实时上升或下降。

3. 错题巩固设计

红灯现在复习
橙灯5分钟后
黄灯1小时后
绿灯1天后

错题不会立刻反复轰炸，而是按间隔节点推送。未到复习时间的题会变暗，暂不推送。

错题进度按红、橙、黄、绿四个节点的完成比例计算。某道错题完成全部节点后，才算真正清空。

如果是笔误导致答错，可以点击“笔误”按钮消耗一格体力，恢复本题原来的巩固节点。体力值会随时间自动回充。

4. 学习理念

间隔练习

把一次性重复改成分时复现，降低机械死记硬背的负担。

可见进度

用进度条和颜色状态显示学习轨迹，提升学习掌控感。

错题优先

把错误视为需要管理的记忆节点，而不是简单的失败记录。

速度递进

先保证正确，再逐步压缩反应时间，从会做到熟练，再到速算。
