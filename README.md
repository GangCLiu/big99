# 大九九（Big99）

大九九是面向中小学生的 20 以内乘法口算练习网站，帮助学习者通过分级计时训练、错题巩固和进度反馈提高口算熟练度。

在线体验：<https://gangcliu.github.io/big99/>

## 功能

- 20 以内乘法口算训练
- 初学、速算、熟练等分级练习
- 错题记录与针对性巩固
- 学习进度和“今日进步”反馈
- 响应式单页界面，可在电脑和移动设备浏览器中使用
- 无需注册；练习数据保存在当前浏览器本地

## 本地运行

项目是一个自包含的静态网页，不需要安装依赖或执行构建命令。

1. 克隆或下载本仓库。
2. 直接用现代浏览器打开 `index.html`。

也可以在仓库目录启动任意静态文件服务器，例如：

```bash
python -m http.server 8000
```

然后访问 <http://localhost:8000/>。

## 项目结构

- `index.html`：应用的完整 HTML、样式、脚本和静态资源
- `LICENSE`：MIT 开源许可证

## 隐私

应用不要求账户登录，也不向远程服务上传练习记录。学习进度使用浏览器本地存储保存；清除浏览器站点数据会同时清除这些记录。
